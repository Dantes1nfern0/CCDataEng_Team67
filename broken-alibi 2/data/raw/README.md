# Sample data (transcribed from Engineering Track.pdf, pages 4-5)

These are the only rows the brief gives. No full dataset has been shared.

- badge_access.csv: 10 rows. Badge Access System (real source: CSV exported nightly).
- device_logs.log: 5 lines. Employee Device Logs (real source: streaming syslog). Kept in the original key=value format.
- transactions.csv: 5 rows. Building Transaction Records (real source: PostgreSQL, real-time). Amount is in dollars.

Timestamps and IDs are copied as printed, including the quirks (space vs T in timestamps, the IP 10.0.7.03).
